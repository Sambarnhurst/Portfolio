01 / WHAT THE ARCHIVE CONTAINS

Three connected experiences.

Preserved pages from the earlier Project HEAVEN website.

01 / INDEX.HTML

Public initiative

A concept proposing a collectively developed town, with an explanatory plan and an interest registry. The original plan is preliminary and the registry is not accepting entries here.

02 / COMMUNITY.HTML

Community hub

Designed screens for posts, profiles, messages, project proposals, community votes, downloadable projects, and the OZREN AI-team concept. They require a new backend.

03 / WORKSPACE.HTML

Member workspace

A personal workspace interface with file management, an editor, and local AI-assistance controls. Its server storage and AI endpoints aren't included in the archived snapshot.

02 / REBUILD ROADMAP

Preserve the vision.
Rebuild the platform.

The next version needs a separately designed identity system, member data storage, secure posting and voting APIs, AI service integration, and a clear deployment model before interactive features can be offered publicly.
