01 / PUBLIC ACCESS

For players

Open the game, register or sign in with a standard player account, then use the online worlds and multiplayer menus. The game requires a computer and browser capable of running its 3D renderer.

Server-dependent game modes may be unstable while development continues.

02 / DEVELOPER ACCESS

For the developer

Open the same live game, sign in with your game's ADMIN account, and use the private Developer Studio, world editor, character tools and other admin-only interfaces.

Only existing authenticated ADMIN roles can access development tools. Updating the game's source code still requires a managed server deployment.
